# Inbox — how to empty it

Everything that lands in `Inbox/` is raw material that has not been turned into notes yet. The goal is an empty Inbox, not a tidy one. Nothing in there should be linked to from a permanent note until it has been processed.

## To process one new work (twenty to thirty minutes)

1. **Capture the material.** The full text of the work, and whatever came back: comments, reviews, replies. Drop both in `Inbox/`. If a script produced them, keep the raw input somewhere labelled *archive, not source material*, so timestamps or original formatting survive.

2. **Read the work and mark what is new.** Three to eight claims per work is typical. Search `Notes/` for a few words of each first: ideas recur, and a restatement belongs in the existing note rather than in a new one. If the new work restates a claim in better words, add the better words to the existing zettel.

3. **Write the work note** from `Templates/Template — Work.md`, move it and the full text to `Sources/`, name the text `Text — <identifier>` (or `Transcript — <identifier>`), and set `status: processed`.

4. **Write the new zettels** in `Notes/`. One claim per note, title as the claim, `source:` pointing at the work note, and a real **Not true when** for each. Link each to at least two existing notes.

5. **Read the feedback properly.** This is where half the value is. For each response that matters: a new objection note if the pushback is new, a person note if they are substantive or recurring, a line in [[Commitments — promises made in public]] if anything was promised.

6. **Source one claim before you move on.** Pick the heaviest number or borrowed frame in the work and find what is actually behind it, following *When asked to research a claim* in `CLAUDE.md`. One per work is enough; the backlog only shrinks if the new material stops adding to it. Set `evidence:` on each new zettel honestly, and write the *Outside the work* line even when it says *Needs source*.

7. **Update the series hub** and any index the work changes.

8. **Write the daily note** saying what you processed and what you noticed.

## What else lands here
Anything captured in a hurry: a comment worth answering later, an idea for the next piece, a link to check. Give it a title and a sentence of context and leave it. Process it next time the vault is open.

## Three cautions
- **Do not skip the feedback.** The objection notes are the most reusable thing in the vault, and the audience commissions more of the work than it looks.
- **A claim repeated is not a claim sourced.** A number that appears in five works and has never been traced to a paper reads like corroboration and is not. Only the *Outside the work* line counts.
- **Check for a collision before naming a zettel.** The vault is more useful with one note and two sources than with two near-identical notes.
