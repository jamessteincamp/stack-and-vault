# Sources — index

Every number, date and quotation in the vault points here. Status: **sourced** (citation given and it says what the note says), **partial** (part of the claim is sourced and the gap is written down), **needs-source** (asserted without one), **contested** (someone disputed it and the dispute is unresolved).

**One note per source, named after the source.** A citation note holds two required things: the citation, and the source's own words or figures, verbatim and short, that the zettels are checked against. It can back several zettels, so it is never tied to one claim. A note for a source not yet found is a placeholder named for the claim, which is why some rows below may read like claims; rename them as the sources turn up. See `99 Templates/Template — Source.md`.

The provenance rule: where figures conflict across datasets, use the more conservative number; personal observations are stated as personal, not as research.
